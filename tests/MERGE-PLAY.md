# 나눔 농장 머지 게임 개선

2026-09-27

- 참고 이미지의 칸 기반 합치기 방식에서 착안. 특정 게임 그림을 복사하지 않고 SVG 그림 5종을 직접 작성했다. 외부 이미지·추가 라이브러리는 사용하지 않았다.
- 씨앗 주머니 → 새싹 화분 → 채소 → 수확 바구니 → 나눔 상자.
- 마우스·터치 드래그, 같은 물건 두 번 선택, 키보드 Enter/Space 지원. 빈칸 이동은 합치기 횟수와 보상을 늘리지 않는다.
- 다른 물건에 놓기와 놀이판 밖 드롭은 합치지 않는다. 서버도 입력·놀이판 ID·재고 형태를 검증한다.
- 합치기 효과와 드롭 가능 위치 표시. 움직임 줄이기 설정 지원. 힌트, 새 판 확인, 저장된 놀이 이어하기 제공.
- 하루 첫 완성 10코인, 같은 날 재완성 무보상 유지. 농장 재고를 차감하지 않는다.

검증:

1. 기존 버전에서 빈칸 이동 테스트가 HTTP 400으로 실패하는 것을 확인했다.
2. tests/merge-unit.mjs 통과: 빈칸 이동, 물건 가치 총량 보존, 잘못된 합치기·지난 놀이 ID 거절, 중복 완료 보상 방지, 날짜별 한도, 판매 수입과 구분.
3. tests/merge-play-browser.cjs: 1360px 마우스와 390px 터치 입력으로 합치기·빈칸 이동·잘못된 조합, 키보드 선택, 새로고침 후 유지, 끝까지 완성과 10코인 검증. 브라우저 JavaScript 오류 없음.

범위: 4×4 칸의 짧은 합치기 퍼즐이다. 참고 이미지 왼쪽의 물리 엔진 기반 굴리기·떨어뜨리기 게임은 이번 범위가 아니다. 휴대폰은 브라우저 터치 이벤트로 검사했으며 실제 기기 검사는 별도다.

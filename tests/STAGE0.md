# 0단계 회귀 테스트

제품 코드를 수정하지 않고 현재 로컬 버전의 회귀 오류를 검사합니다.

## 실행

```powershell
node tests/stage0-regression.cjs
```

- 기본 주소: http://127.0.0.1:8792 (TEST_URL로 변경 가능, localhost만 허용)
- 실행 중인 로컬 서버, Playwright/Edge 및 sharp가 필요합니다.
- 런타임 패키지 경로는 TEST_RUNTIME으로 지정할 수 있습니다.
- 로컬 private/teacher-setup.txt를 읽어 별도의 2명 테스트 학급을 생성합니다. 기존 학생 계정을 사용하지 않습니다.
- 체험 모드는 매 실행마다 별도의 체험 키를 생성합니다.
- 실패가 있으면 종료 코드 1, 실행 자체 오류는 2입니다.
- 결과: test-output/stage0/report.json 및 PNG 캡처, 좌표 JSON.

## 검사의 범위와 한계

1. 번호표 중심이 해당 3D 밭 흙바닥 투영 영역 안에 있는지 6칸 모두 검사합니다. 그림의 픽셀별 분할 검사는 아닙니다.
2. 마을 왕복을 3회 수행하며 장면 객체·캔버스 픽셀 분산·농장 전용 UI 숨김을 검사합니다. 픽셀 분산만으로 지도 내용의 정확성을 보장하지 않습니다.
3. 1번 밭에 심었을 때 서버 상태가 해당 칸만 바뀌고, 실제 표시되는 아틀라스 이미지 또는 씨앗 도형도 바뀌는지 검사합니다. 이 단계가 실패하면 뒤의 물 주기 검사는 실행되지 않습니다.
4. 서버의 농장·재고 보존과 주소/화면 복원을 별개의 테스트로 검사합니다.
5. 도서관 전후 탭 목록을 비교합니다.
6. 390px 도서관 가로 넘침과 JS 예외를 검사합니다. 전체 모바일 흐름이나 물리적 터치 장치 검증을 대신하지 않습니다.

장면 좌표 관측을 위해 테스트 브라우저에서 farm3d.js 응답에 읽기 전용 진단값 수집을 삽입합니다. 저장 파일이나 게임 상태는 변경하지 않습니다. 수정 완료 판정 때에는 진단 삽입 없는 일반 브라우저에서도 별도 화면 검사가 필요합니다.

현재 단계는 실패 확인까지만입니다. 제품 수정·데이터 이전·배포는 포함하지 않습니다.

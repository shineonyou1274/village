# 남은 화면 다섯 항목 정리

2026-09-28

## 변경

1. 씨앗은 큰 노란 알갱이, 새싹은 줄기와 두 잎, 성장한 작물은 잎이 찬 모형으로 분리했다. 작물은 흙칸 크기에 맞춰 키웠고 농장 기본 시점을 PC 1.45배, 작은 화면 1.15배로 조정했다. 마을 전체 시점은 유지한다.
2. 별빛도서관·여권 머리글에 기존과 같은 코인 표시를 추가했다. 로그인한 본인의 서버 상태에서 코인을 읽는다. 오른쪽의 중복 신원 문구를 숨기고 브랜드·탭의 글꼴과 폭을 공통 스타일로 맞췄다. 공부 포인트 P와 코인은 합산하지 않는다.
3. 방향 버튼은 ‘산책 켜기’에서만 표시한다. 회전·확대·기본 시점·따라가기는 접힌 ‘지도 보기 설정’ 안에 둔다. 화면을 바꾸면 접힌 기본 상태로 복귀한다.
4. 지도 조작 안내는 지도 아래 완결된 문장 하나로 모았다. 작업 중 진행 알림은 별도 상태 영역에 남긴다.
5. 우리 마을에서는 개인 농장 이름표를 표시하지 않는다.

## 검증

- 수정 전 tests/ui-polish.cjs: 체험·학급 × 1360px·390px에서 조작부, 안내, 이름표, 코인 머리글 검사가 실패하는 것을 확인했다. 이전 보고서는 test-output/ui-polish/before.json에 보관했다.
- 수정 후 같은 검사에 밭 번호가 화면 안에 남는 검사를 추가: 24개 통과.
- tests/stage0-regression.cjs: 기존 지도 왕복, 번호/작업 일치, 새로고침 후 상태 유지, 공통 탭, 모바일 폭과 오류 검사를 유지했다. 새싹을 별도 모형으로 분리했으므로 읽기 전용 시각 검사에서도 그 모형을 관찰하도록 갱신했다.
- tests/stage1-view-switch.cjs: 애니메이션을 멈춘 상태의 전환, PC·390px × 체험·학급 4개 통과.
- tests/campus-unit.mjs: 기존 권한·개인정보·타이머·보상 불변 조건 12개 통과.
- 390px에서 옛 game-dock 하단 메뉴가 나타나지 않고 주요 탭이 하나만 보이는 것을 검사했다. 실제 휴대폰 기기 테스트는 아니며 브라우저 화면 폭 검사다.

# 첫 화면 레이아웃 검증 (2026-10-15)

## 범위
게임 규칙, 서버 API, 거래/접속 상태, 계정과 저장 데이터는 변경하지 않았습니다. 안내의 기본 열림 상태, 기존 DOM 컨트롤 배치, CSS 높이 및 장터 카메라의 화면 표시 범위만 변경했습니다.

- 1100px 이상: 공통 상단 바 64px, 5개 탭 포함 한 줄.
- 1100px 미만: 상단 정보 영역 64px + 탭 40px. 휴대폰은 정보 영역 안에서 날씨를 한 줄로 분리합니다.
- 농장 체험 안내와 학급 길잡이는 기본 닫힘, 지도 안 도움말. 메뉴에서도 다시 열 수 있습니다.
- 지도 높이: max(420px, 100dvh - 상단 바 높이).
- 장터의 기존 도구 및 선택한 친구 카드는 지도 위에 배치하고, 긴 친구 카드는 자체 스크롤을 허용합니다.

## 로컬 브라우저 실측
Edge/Chromium 자동 검사에서 아래 크기는 **웹 콘텐츠 viewport 크기**입니다. 모니터나 브라우저 바깥 창 크기가 아닙니다.

| 콘텐츠 화면 | 상단 | 농장 | 우리 마을 | 장터 |
|---|---:|---:|---:|---:|
|1440×900|64|836|836|836|
|1366×768|64|704|704|704|
|1280×720|64|656|656|656|
|1280×600 (브라우저 도구 모음 공간을 추가로 뺀 조건)|64|536|536|536|
|1100×720|64|656|656|656|
|1024×768|104|664|664|664|
|768×1024|104|920|920|920|
|390×844|104|740|740|740|

학급 모드 1366×768도 지도 세 곳 모두 704px. 총 27개 조합에서 가로 넘침, 불필요한 페이지 스크롤, 페이지 JavaScript 오류 없음. 지도 안 안내 열기/접기, 메뉴에서 안내 다시 열기, 시세표 열기/Esc 닫기 확인. 좁은 장터 카메라 조정 후 768×1024와 390×844 재확인.

## 검증 한계
설치된 Whale 실행 파일은 자동 검사 연결 전에 종료되어 실제 Whale UI의 북마크바 ON 상태는 확인하지 못했습니다. 위 수치는 Edge에서 실제 렌더링한 결과이며, 1280×600은 브라우저 UI를 고려한 추가 검증 조건이지 Whale 북마크바의 실측 높이가 아닙니다.

재현: 로컬 서버 실행 뒤 `node tests/play-layout.cjs`, `node tests/play-layout-navigation.cjs`. 테스트는 격리된 로컬 DB에 체험/학급 계정을 생성합니다.

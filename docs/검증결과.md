# 이어지는 마을 — 검증 결과

검증일: 2026-09-21. 학교용 시제품, 실명 없는 가상 계정으로 검사했습니다.

## 확인한 흐름

- 학생 코드 입장, 서버 권한 확인, 다른 학급 접근 차단.
- 3D 씨앗 심기·물주기 저장, 성장 시간 전 수확 거부.
- 교사 장터 개장 → 별도 학생 두 명 생산 → 교환 제안 → 수락 → 양쪽 재고 반영.
- 새로고침 후 진행 보존, 교사 일시정지, 휴대폰 폭 390px에서 가로 넘침 없음.
- 중복 저장 요청 12개는 한 번만 처리, 음수 재고와 임의 재고 조작 거부.
- 같은 거래에 30명 동시 수락 시 1명만 성공, 전체 물품 수량 보존.
- 교사와 학생 브라우저 흐름에서 자바스크립트 페이지 오류 없음.

## 온라인 서버 부하 측정

배포된 Cloudflare Worker + D1에 한 대의 검사 기기에서 120개 가상 계정으로 HTTP 요청을 동시에 보냈습니다. 수치는 요청의 95%가 완료되는 시간입니다. 실제 120대 브라우저나 학교 무선망의 측정이 아닙니다.

| 검사 | 개선 전 | 개선 후 |
|---|---:|---:|
| 120명 동시 입장 | 8.86초 | 7.01초 |
| 120명 상태 조회 | 6.74초 | 4.72초 |
| 120명 생산 저장 | 10.01초 | 6.69초 |
| 한 거래에 30명 동시 수락 | 3.95초 | 3.53초 |

생산 저장의 95% 응답시간은 약 33% 줄었습니다. 120개 동시 입장·조회·생산은 모두 성공했습니다. 거래 경합에서는 의도대로 1명 성공, 나머지는 이미 처리된 거래로 거부됐습니다.

최적화: 학생·학급 조회 합치기, 독립 조회 병렬 처리, 단순 생산 응답에서 전체 학생 목록 제외, 최근 접속 갱신 횟수 제한, 학생별 새로고침 시간 분산, 그림자와 고해상도 렌더링 축소, 안내창 뒤 3D 일시정지.

로컬 서버는 120명 생산 저장 95% 기준 0.73초였습니다. 이 값을 온라인 성능으로 표시하지 않았습니다.

## 한계와 남은 현장 확인

- ‘병목이 전혀 없다’고 보증할 수 없습니다. 온라인에서 동시에 누르면 수 초의 저장 대기가 측정됩니다.
- 학교 와이파이, 기기별 GPU·메모리, 네트워크 필터, 120대의 장시간 플레이는 현장 확인이 필요합니다.
- 소프트웨어 그래픽 렌더러를 강제한 반복 검사에서 브라우저 시간 초과가 발생했습니다. 그래픽 가속을 사용하는 별도 검사에서는 교사·학생 전체 흐름이 통과했습니다. 매우 낮은 사양의 기기는 별도 시범 운영 대상으로 두어야 합니다.
- 배포 접근 권한은 소유자 전용입니다. 학생용 공개 전환은 별도 승인 단계이며 학급 데이터는 입장 코드로 보호합니다.

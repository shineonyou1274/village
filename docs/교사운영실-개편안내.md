# 교사 운영실 화면 개편 · PDF 수정 안내

- 기본 탭: **수업 중**. 수업 리모컨, 공동 식탁, 고마운 이웃 도장, 참여 현황.
- **수업 준비**: 학생별 입장 링크·QR, 직업 배정, 공동 식탁 목표 인원.
- **기록·설정**: 기록 백업·CSV, 별빛도서관 좌석·공부 기록, 여권 출석 기준·공동 식탁 시즌, 여러 반 연결, 새 학급 만들기.
- 초기화는 기록·설정 맨 아래 접힌 **위험 구역 · 학급 활동 초기화**. 백업, 학급 코드 입력, 직업 방식 선택, 최종 확인 절차는 동일합니다.

## 심사용 PDF에서 바꿀 경로

기존: 수업 운영 → 날씨·경제 상황 → 폭우 · 배송 지연 → 학급 전체에 적용

변경: **수업 중 → 수업 리모컨 → 날씨·경제 상황 → 폭우 · 배송 지연 → 학급 전체에 적용**

진행·일시정지, 장터, 시즌, 날씨, 날짜를 선택한 뒤 **학급 전체에 적용**을 눌러야 저장됩니다. 변경할 때만 적용 버튼이 강조됩니다. 상단 상태는 저장된 값입니다.

공동 식탁 시작/목표: 수업 중 → 공동 식탁 → 목표 인원 조정 → 수업 준비의 공동 식탁 목표 인원.

## 변경 범위

교사 화면의 기존 컨트롤을 옮기고 안내를 접었습니다. 기존 API, 인증, 보상, 게임 규칙, 서버 데이터 처리 코드는 수정하지 않았습니다. 실기능 검증은 별도 로컬 학급에서 수행했습니다. E02B01·1D86B5 온라인 학급은 조작하지 않았습니다.

여권의 이전 미션 탭은 스탬프 탭과 같은 달성 조건 목록이었습니다. 여권 탭 통합은 실제 복구·협력 미션을 제거하지 않습니다.

# 진로 체험 첫 화면 정리 검증 (2026-10-16)

## 범위
- 화면·안내만 수정. src/, 서버 API, 재고·교환·수확·학급 데이터 로직은 변경하지 않음.
- 체험 기본 직업(기존 채소 농업인)을 '채소 농부 · 체험 마을'로 표시.
- 첫 방문 소개 카드, 생산 → 교환 → 기여 3단계 목표. 학급의 4가지 기존 직업에 맞는 생산 안내.
- 일반 농사 성공 토스트·하단 상태줄 중복 제거. 밭 카드 유지, 수확량 잠깐 표시, 첫 수확 안내는 운반 종료 후 표시.
- 여권 미션 탭 통합, 첫 수확/첫 교환/첫 나눔/공동 식탁 기여/직업 생산 3회 우선 표시, 교과 탐험가 🧭.

## 진행 표시의 범위
서버 도장 발급·보상은 추가하지 않았다. 기존 첫 수확 등 계정 도장은 그대로 읽는다.
새 교환·나눔·기여·생산 진행은 기존 상태/최근 활동 기록과 확인된 성공 응답을 읽고, 학급·학생별로 이 브라우저에 표시 이력을 보관한다.
다른 기기에서는 기존 상태/최근 기록으로 확인 가능한 범위가 표시되며, 서버에 없는 전체 과거 생산 횟수를 새로 복원하지는 않는다.

## 검증
- 실제 로컬 체험: 심기 → 물 주기 → 성장 → 수확. 수확 직후 안내 숨김, 운반 종료 후 짧은 안내 표시.
- 실제 로컬 체험: 상추로 연습 친구 우유 교환 → 우유 공동 식탁 기여. 기존 서버 재고 처리와 체크 표시 정상.
- 직업 생산 3회 후 새 활동 카드 완료 표시.
- 1366×768, 1280×720, 768×1024, 390×844에서 농장/마을/장터 페이지 추가 스크롤·가로 넘침 없음. 콘솔 pageerror 없음.
- 로컬 균등 무작위 4인 학급에서 채소/낙농/과수/양식 직업별 소개·목표 정상.
- 실제 웨일 북마크바 ON은 미검증. 위 화면 크기는 Edge 자동 브라우저 테스트 결과.

## 보존
- 기존 E02B01과 심사용 1D86B5 계정은 사용하거나 변경하지 않음.
- 효과음·3단계 이후 가이드 투어는 이번 범위에서 제외.
- 2026-10-19~2026-10-26 배포 금지.

온라인 별도 체험 계정에서 심기·물주기·수확, 운반 후 안내, 상단 직업 및 목표 표시 확인. 첫 수확 도장의 서버 목록 지연은 이미 확인된 수확 수량으로 즉시 보완하며 단위 검증 통과.

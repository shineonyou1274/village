# 이어지는 마을 — 학교 수업 시작 안내

학생 접속: https://ieum-village-play-0921.peace-shiny.chatgpt.site/

교사 운영실: https://ieum-village-play-0921.peace-shiny.chatgpt.site/teacher.html

준비된 학급 코드는 **E02B01**, 인원은 **120명**입니다. 현재 사이트는 소유자만 볼 수 있습니다. 학생 접속용 공개 전환이 완료된 뒤 아래 순서대로 시작하세요. 공개 전환 이후에도 학급 데이터에는 학생 또는 교사 입장 코드가 필요합니다.

## 교사가 준비할 것

1. 프로젝트의 `private/교사용-시작정보.txt`에서 교사 입장 코드를 확인합니다.
2. 운영실에 학급 코드와 교사 입장 코드를 넣습니다.
3. `private/학생별-입장코드-120명.csv`에서 각 학생에게 **본인 행만** 나누어 줍니다. 전체 CSV를 학생에게 배포하지 않습니다.
4. 서로 다른 실제 기기 2대로 입장·교환·새로고침을 먼저 확인합니다. 학교 와이파이에서 120대가 동시에 작동하는 현장 검증은 아직 하지 않았습니다.

실명은 수집하지 않고 학생 001~120으로 시작합니다. 초기 역할은 4종류를 균등하게 배정했으며, 학생은 첫 생산 전에 ‘직업’ 버튼에서 바꿀 수 있습니다. 입장 코드는 재접속할 때도 같으므로 다음 차시까지 보관합니다.

## 첫 차시 40~45분 예시

| 시간 | 교사 진행 | 학생 활동 |
|---|---|---|
| 0~5분 | 개인 성장·맑음·장터 닫기로 시작 | 자기 코드로 입장하고 역할 선택 |
| 5~15분 | 생산 과정 관찰 | 밭 심기 → 물 주기 → 성장 → 수확·보관, 직업별 생산 |
| 15~25분 | 장터 열기 → 학급 전체에 적용 | 상추·우유·사과·생선 교환 제안과 수락 |
| 25~35분 | 협력 시즌으로 전환 | 각 물건을 공동 식탁에 보태기 |
| 35~45분 | 일시정지 → 활동 현황 CSV 저장 | ‘내 물건이 누구에게 필요했나’, ‘내 일을 가능하게 한 다른 직업은?’ 이야기하기 |

협력 목표는 각 물건 30개입니다. 모인 수량과 개인 기여는 교사 화면에서 확인합니다. 새 차시에는 날짜를 올려 직업 생산과 오늘의 퀴즈를 다시 사용할 수 있습니다. 장터 개장, 날씨, 개인/협력 시즌은 서로 독립적으로 조절합니다.

## 주요 조작

- 빈 밭을 누르면 농부가 걸어가 씨를 심습니다. 같은 밭에 물을 주면 약 20초 동안 자랍니다. 수확물은 농부가 보관소에 내려놓을 때 서버에 기록됩니다.
- 여러 밭을 선택하면 순서대로 작업합니다. ‘예약 취소’는 대기 작업을 지웁니다.
- 직업 생산은 하루 3회입니다. 상추밭 재배와 별도이며, 생산량은 작업장 단계에 따라 달라집니다.
- 장터 제안 물건은 잠시 장터에 맡겨집니다. 수락 시 양쪽 재고가 함께 처리되고, 취소하면 물건이 돌아옵니다. 같은 제안을 여러 명이 누르면 한 명만 성공합니다.
- 폭우는 생산을 잠급니다. 안전 복구 미션을 해결하고 활동을 재개합니다. 날씨·수요·공급에 따라 게임 속 가상 시세가 달라집니다.
- 전체 마을의 직업 구역을 누르면 해당 역할의 실제 학급 친구 목록을 볼 수 있습니다. 현재 지도는 구역별 공유 지도이며, 학생 120명의 이동을 실시간 아바타로 보여주는 기능은 아닙니다.
- 교사의 일시정지는 서버에서 즉시 적용됩니다. 다른 학생 화면의 자동 갱신은 보통 10~15초 간격입니다. ‘새로 확인’으로 즉시 다시 읽을 수 있습니다.

## 연결이 느리거나 끊겼을 때

‘저장 확인 중’이면 기다립니다. 네트워크가 끊기면 새 행동을 잠그고, 같은 저장 요청으로 복구하여 중복 지급을 방지합니다. ‘새로 확인’을 누르거나 다시 접속합니다. 진행 중인 이동 애니메이션과 대기 작업은 다시 시작해야 할 수 있지만, 완료된 재고·밭 상태·거래는 서버에 남습니다. 저장 확인이 끝나기 전에 코드를 다른 학생에게 넘기지 마세요.

노트북·태블릿·휴대폰 화면을 지원합니다. 3D를 시작하지 못한 브라우저에서는 2D 밭으로 계속 플레이할 수 있습니다. 배터리 절약을 위해 그림자를 줄였으며 안내창과 숨긴 탭에서는 3D 계산을 쉽니다.

## 이번 시제품의 범위

구현: 4개 직업, 3D 상추 농사와 작업 예약, 서버 저장, 학생 간 물물교환, 교사 제어, 날씨·시세, 공동 기여, 활동 CSV.

후속 확장: 머지 미니게임, 학생마다 자유롭게 짓는 건물과 도로, 항공사·복합 물류, 120명 실시간 이동 아바타, 자동 시즌 초기화와 여러 시즌 기록 비교. 현재 목장·과수·양식은 역할 생산 버튼으로 생산하며 상추와 같은 개별 생장 애니메이션은 없습니다.

## 현장 사용 판단

온라인 서버에서 가상 계정 120개의 동시 요청을 검증했지만, 실제 학교 기기 120대와 와이파이 혼잡을 보장하는 결과는 아닙니다. 우선 10~20명으로 짧게 시범 운영한 뒤 기기·통신 상태를 확인하고 120명으로 확대하세요. 상세 측정은 `검증결과.md`에 있습니다.

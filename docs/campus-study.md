# 네 학급과 별빛 공부학교

## 교사 운영
- `private/네학급-교사시작정보.txt`의 새 1반 학급 코드와 교사 코드로 교사 운영실에 입장합니다.
- **관리할 학급**에서 1~4반을 전환합니다. 기존 수업 날짜·날씨·장터·일시정지·협력 이야기 운영은 선택한 반에 적용됩니다.
- 반별 마을 이름을 바꿀 수 있습니다. 여행 및 공부학교 개방 설정은 연결된 네 반 전체에 적용됩니다.
- 각 반 정원은 30명입니다. 24명이 참여하면 해당 반 학생 코드 24개만 배부합니다. 기존 E02B01 학급과 기록은 별도로 유지합니다.
- 학급 연결에는 상대 학급의 교사 코드가 필요합니다. 연결된 모든 교사 코드는 네 반을 관리할 수 있으므로 교사만 보관하세요.
- 공부 기록은 선택한 반의 최근 240회까지 조회·CSV 저장합니다. 반별 학생 파일은 `private/1반 마을-학생입장코드.csv` 등입니다.

## 학생의 여권 여행
- 마을 화면의 **여권 · 마을 여행**을 엽니다.
- 이웃 존중 약속을 고르고 여권을 받습니다.
- 교사가 여행을 열면 연결된 마을을 선택해 친구의 별명·직업·농장 규모와 심은 밭을 구경하고 도장을 모읍니다.
- 소속과 농장 재고는 그대로 유지됩니다. 이 버전은 방문 기능이며 반 사이 물건 교환은 제공하지 않습니다.

## 함께 공부하기
- 마을의 **별빛 공부학교**를 열어 목표, 15/25/40분 중 시간, 자리를 선택합니다.
- 서버 시간을 기준으로 기록합니다. 약 15초마다 연결을 확인하며, 45초 넘게 연결이 끊기면 그 미확인 구간은 기록하지 않고 휴식 상태가 됩니다.
- 다른 앱 또는 종이책 사용을 허용합니다. 기기 잠금·절전이나 모바일 브라우저 제한으로 연결이 끊기면 다시 돌아와 재개합니다.
- 같은 계정에서 동시에 두 집중 세션을 만들 수 없습니다. 연결을 유지하는 것만으로 실제 공부했음을 인증하지는 않습니다.
- 마무리 때 실제 집중 시간을 기록된 시간 이내의 분 단위로 선택하고 한 일을 적습니다. 1분 미만도 0분으로 기록을 남길 수 있지만 보상은 없습니다.
- 1분 이상 마무리하면 1분당 1P와 마무리 5P, 한국 시간 기준 하루 최대 30P를 받습니다. 야간 가산점·순위는 없으며 마을 코인과 별개입니다. 포인트 사용 상점은 아직 제공하지 않습니다.
- 친구에게는 별명·학급·자리·집중/휴식 상태만 보입니다. 목표와 마무리는 본인 및 연결된 학교의 교사만 확인할 수 있습니다.

## 확인 범위
- 권한 분리, 4개 학급 제한, 여권·여행 개방, 공부 목표 비공개, 서버 시간, 휴식·연결 단절, 보상 중복 방지 및 하루 상한을 자동 검증합니다.
- 브라우저에서 실제 1분 경과와 저장·재접속, 모바일 화면, 학급별 운영 분리를 검증합니다.
- 동시 부하는 한 컴퓨터의 HTTP 요청으로 측정하며 실제 학교 120대 기기·무선망 검증을 대체하지 않습니다.
- 기존 사이트 공개 범위를 유지합니다. 현재 소유자 전용 비공개이므로 학생 실사용 전 별도 접근 범위 설정이 필요합니다.

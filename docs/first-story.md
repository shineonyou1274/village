# 첫 협력 이야기: 내일 아침 급식을 부탁해!

## 교사 준비
- 교사 운영실에서 학급 코드와 교사 코드로 입장합니다.
- 실제 활동할 인원을 입력하고 **우리 반 이야기 시작**을 누릅니다.
- 시작하면 폭우, 협력 시즌, 장터 닫힘이 적용됩니다. 기존 재고는 유지됩니다.
- 120명 기준 직업 미션마다 서로 다른 학생 15명, 재료마다 30개가 필요합니다.
- 목표는 시작할 때 고정됩니다. 중간 참여 인원이 줄면 목표 달성이 어려울 수 있으므로 실제 인원으로 시작하세요. 이 시제품은 학급당 첫 이야기를 한 번 진행하며 반복 활동에는 새 학급을 사용합니다.

## 활동 흐름 (예상 15~20분, 학급에 따라 조절)
1. 학생은 상단 노란 이야기 안내 또는 협력 시즌을 엽니다.
2. 운송 관리자와 전력 설비 기술자 문제를 풀어 길과 창고를 복구합니다. 한 학생이 여러 직업을 탐험할 수 있지만 같은 미션으로 두 번 기여할 수 없습니다.
3. 길 복구 후 장터가 열립니다. 길·전기가 모두 복구되면 생산과 재료 기여를 진행합니다.
4. 상추·우유·사과·생선을 보탭니다. 재료는 내 보관함에서 차감됩니다. 서로 필요한 물건을 교환할 수도 있습니다.
5. 모든 재료가 모이면 품질 검수, 다음으로 급식 인계 미션이 열립니다.
6. 완료 화면의 **우리가 보탠 일**을 보며 내가 의지한 직업을 설명합니다. 교사는 이야기 참여 기록 CSV를 저장할 수 있습니다.

## 혼자 미리 보기
학생 입장 창에서 **혼자 연습하기** → 직업 선택 → 노란 이야기 안내 → **혼자 이야기 연습하기**. 연습용 재료는 각 2개를 한 번 받을 수 있으며 학급 기록과 분리됩니다.

## 운영과 검증 범위
- 교사의 일시정지, 서버 저장, 중복 보상 방지와 마지막 재료 동시 기여 제한을 적용했습니다.
- 학생 표시와 다른 학생의 진행 반영에는 최대 약 15초가 걸릴 수 있습니다.
- 자동 검증은 API 동시 요청과 데스크톱/모바일 크기의 브라우저를 사용합니다. 실제 120대의 기기와 학교 네트워크를 검증한 것은 아닙니다.
- 현재 사이트 공개 범위는 기존 설정을 유지합니다. 수업 전 학생 기기에서 사이트 접근과 학생 코드 입장을 확인하세요.
